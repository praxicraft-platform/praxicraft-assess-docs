Your plan controls monthly invites, how many assessments you can keep, seats on the team, and whether API keys or ATS features are available.

## If you are recruiting / ops

Check your plan and remaining invites in the [dashboard](https://assess.praxicraft.com/assess) (billing / usage) or ask eng to call `GET /org/billing/` (or invite fields on `GET /org/`).

### Quick rules

- Invites reset monthly at **00:00 UTC on day 1**.
- Re-inviting the **same person** to the **same** assessment does **not** use another invite.
- Inviting them to a **different** assessment **does** count again.
- Only **Active** assessments accept invites.
- When you hit the cap, new invites fail until next month or you upgrade — existing results stay readable.
- A **pipeline with multiple assessment stages** can consume one invite **per stage** as people progress.

## Summary table

| Plan | Monthly invites | Active assessments | Seats | API keys | API R/W per hour |
|------|-----------------|--------------------|-------|----------|------------------|
| Free | 50 | 3 | 2 | No | — |
| Starter | 500 | 15 | 5 | Yes | 500 / 100 |
| Growth | 1,000 | 50 | 15 | Yes | 2,000 / 400 |
| Enterprise | Unlimited | Unlimited | Unlimited | Yes | 10,000 / 2,000 |

API rate details: [Rate limits](/guides/rate-limits).

## Feature gates (common)

| Feature | Typical plan |
|---------|----------------|
| Public API keys | Starter+ |
| Org usage / developer health / audit export API | Starter+ |
| Session recording | Starter+ |
| Screen / webcam recording, pool mode, hiring squads | Growth+ |
| Pipeline create via Public API | Growth+ |
| ATS integrations | Growth+ |
| Audit log API | Starter+ |
| Hybrid interviews | Growth+ |

Upgrade changes can take up to ~60 seconds to show on `GET /org/`.

## For engineers

Quota exhausted → **403** `INVITE_QUOTA_EXCEEDED`. Assessment caps → `ASSESSMENT_LIMIT_REACHED` / `LIMIT_REACHED` / `PLAN_REQUIRED`.

Successful GETs often include:

```json
{
  "meta": {
    "plan": "starter",
    "invite_limit": 500,
    "invites_used": 42,
    "invites_remaining": 458
  }
}
```
