**Shipped:** 2026-08-23 · **OpenAPI:** `1.4.0` · **Prefix:** `/api/v1/public/`

## Added

- `POST /pipelines/create/`: Linear pipeline + stages (Growth+, mode-scoped)
- `PATCH /pipelines/{slug}/`: Metadata and stages replace (append-only after enrollments)
- `POST /pipelines/enrollments/{id}/advance/`
- `GET` / `POST /pipelines/enrollments/{id}/notes/`

## Changed

- `pipelines:write` now covers structure writes and advance/notes (in addition to enroll/hold/reject)
