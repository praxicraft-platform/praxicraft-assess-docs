This feed covers the **Assess Public API** under `/api/v1/public/`. Product and marketing releases stay on the [product changelog](https://praxicraft.com/changelog).

## Versioning

| Layer | Rule |
|-------|------|
| URL prefix | Stays `/api/v1/public/` until a true path v2 |
| OpenAPI `info.version` | SemVer — minor for additive endpoints/fields; major only for breaks |
| These pages | One entry per OpenAPI version, newest first in the sidebar |

Live and Test mode (`ct_live_…` / `ct_test_…`) apply unless an entry says an endpoint is **org-global**. Details: [Authentication — Live and Test mode](/authentication#live-and-test-mode).
