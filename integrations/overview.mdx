## Two loops (do not mix them up)

| Path | What Assess creates | Who it is for |
|------|---------------------|---------------|
| **Native connectors** (Growth+) | An **AI interview room**, then an unstructured note on the application | Live screens inside Greenhouse, Lever, Ashby, Workday, BambooHR, Zoho Recruit, or Breezy HR |
| **Zapier / n8n / Make / webhooks** | An **assessment invitation** or pipeline enroll | Take-home / async screens. and long-tail ATS |

Native connectors do **not** send assessment invites today. A Greenhouse stage change does not create a take-home link unless you add Zapier, n8n, or Make.

## For engineers

Scope for status endpoints: `organisation:read`.

| Method | Path | What you get |
|--------|------|----------------|
| GET | `/integrations/` | `integrations[]` with `webhook_url`, `connect_url`, `has_api_key`, `is_active` (no secrets) |
| GET | `/integrations/{provider}/connect/` | Dashboard `connect_url` + whether OAuth is available |
| POST | `/integrations/{provider}/test/` | `{ ok, connect_url }`. `404 NOT_CONFIGURED` if never connected |

Open `connect_url` in a browser as owner, admin, or developer. do not complete OAuth from a server alone.

Providers post into Assess at:

```text
https://assess.praxicraft.com/api/v1/integrations/webhooks/{provider}/?org={organisation_uuid}
```

Those inbound webhooks create **interview rooms**, not assessment invites. Destinations (HTTPS / Slack / Teams) use `/webhooks/`: See [Webhooks](/guides/webhooks).
