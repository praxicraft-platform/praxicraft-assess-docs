## Current surface (1.7.0)

Additive resources since the 1.1.0 baseline. details in the [API changelog](/api-changelog):

| Area | Paths | Notes |
|------|-------|--------|
| Jobs & applications | `/jobs/…`, `/applications/…` | Openings, apply, advance/reject/hold; scopes `jobs:*`, `applications:*` |
| Screening | `/jobs/{key}/requirements/…`, `/applications/{id}/screening/…` | L3 rank + optional L4; `screening:write` for reruns |
| Candidate CRM | `/candidates/…` | Profiles, notes, tags, scorecards, merge; `profiles:*` (not `candidates:read`) |
| Org reads | `/org/usage/`, `/org/developer/health/`, `/org/billing/`, `/org/audit-log/export/` | Mode-scoped usage/health/export; billing is org-global |
| Org writes | `PATCH /org/`, `/org/squads/…`, `/org/member-invites/` | Scope `organisation:write` for mutations |
| Pipelines | `POST /pipelines/create/`, enrollments, advance, notes | Linear stages; Growth+; `cv_screen` with jobs |
| Destinations | `/webhooks/` (+ delivery retry) | Includes job / application / CRM events |

Guides: [Jobs](/guides/jobs) · [Screening](/guides/screening) · [Candidate profiles](/guides/candidates) · [Organisation](/guides/organisation) · [Pipelines](/guides/pipelines) · [Scopes](/guides/scopes) · [Webhooks](/guides/webhooks).

## Playground notes

- Auth: Bearer token (`ct_live_…` or `ct_test_…`)
- Server: `https://assess.praxicraft.com` (paths under `/api/v1/public/…`)
- Example languages: curl, Python, JavaScript, Node, Go

Paste keys only in trusted environments. Prefer [SDKs](/sdks/introduction) for production apps.

## Conventions

- Flat JSON success bodies
- Errors: `{ "error": { "code", "message", "details?" } }`
- Invitation id: **`invite_token`**
- Job path id: slug or UUID
- Cursor pagination: `cursor`, `page_size` (default 20, max 100)
- Audit export format query: **`export_format`** (`csv` \| `json`). not `?format=` (DRF renderer)
