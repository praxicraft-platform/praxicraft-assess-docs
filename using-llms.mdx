These formats keep AI answers grounded in the real Public API. If you only hire from the dashboard, you can ignore this page.

## If you just need to hire

You do not need this page. Use the [Assess dashboard](https://assess.praxicraft.com/assess) or the [Quickstart](/quickstart) dashboard path.

## If you use AI tools

Prefer the full stack on [Build with agents](/build-with-agents) (Knowledge MCP + API MCP + skills). This page covers docs-only formats.

### llms.txt

Full index: [https://docs.praxicraft.com/llms.txt](https://docs.praxicraft.com/llms.txt)

Each guide also has a `.md` variant (for example `/quickstart.md`).

### Knowledge MCP

Search and read these docs from any MCP client (no credentials):

```json
{
  "mcpServers": {
    "praxicraft-assess-knowledge": {
      "url": "https://docs.praxicraft.com/mcp"
    }
  }
}
```

### Skills

```bash
npx skills add https://docs.praxicraft.com
```

Or install the Agent Plugin suite — [Build with agents](/build-with-agents).
