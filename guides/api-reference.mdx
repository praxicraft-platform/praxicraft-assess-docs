## Current surface (1.4.0)

Additive org/ops endpoints since the 1.1.0 baseline. details in the [API changelog](/api-changelog):

| Area | Paths | Notes |
|------|-------|--------|
| Org reads | `/org/usage/`, `/org/developer/health/`, `/org/billing/`, `/org/audit-log/export/` | Mode-scoped usage/health/export; billing is org-global |
| Org writes | `PATCH /org/`, `/org/squads/…`, `/org/member-invites/` | Scope `organisation:write` for mutations; member-invite list is read-only |
| Pipelines | `POST /pipelines/create/`, `PATCH /pipelines/{slug}/`, enrollments `advance` + `notes` | Linear stages; Growth+; `pipelines:write` |
| Destinations | `/webhooks/` (+ delivery retry) | Same as Developer → Destinations; no separate `/destinations/` path |

Guides with curl and Live/Test callouts: [Organisation](/guides/organisation) · [Pipelines](/guides/pipelines) · [Scopes](/guides/scopes) · [Webhooks](/guides/webhooks).

## Playground notes

- Auth: Bearer token (`ct_live_…` or `ct_test_…`)
- Server: `https://assess.praxicraft.com` (paths under `/api/v1/public/…`)
- Example languages: curl, Python, JavaScript, Node, Go

Paste keys only in trusted environments. Prefer [SDKs](/sdks/introduction) for production apps.

## Conventions

- Flat JSON success bodies
- Errors: `{ "error": { "code", "message", "details?" } }`
- Invitation id: **`invite_token`**
- Cursor pagination: `cursor`, `page_size` (default 20, max 100)
- Audit export format query: **`export_format`** (`csv` \| `json`). not `?format=` (DRF renderer)
