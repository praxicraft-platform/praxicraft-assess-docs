Ashby supports both Assess loops: **native** (Growth+) creates an AI interview room and writes a note on the application; **automations** send assessment invites from your take-home stage.

## Native connector (Growth+)

<Steps>
 <Step title="Open Integrations">
 In the [Assess dashboard](https://assess.praxicraft.com/assess), go to **Settings → Integrations**.
 </Step>
 <Step title="Connect Ashby">
 Use an API key **or** OAuth.
 </Step>
 <Step title="Confirm">
 Matching events can create an **interview room**; score-back is an unstructured note. Stage filters are **not** applied.
 </Step>
</Steps>

## Cookbook. stage → assessment invite → score back

Use [Zapier](/integrations/zapier), [n8n](/integrations/n8n), or [Make](/integrations/make).

**Golden recipe:** Ashby interview stage **Take home** → invite → note on the application.

<Steps>
 <Step title="Invite">
 1. Trigger: Ashby **Candidate Stage Changed** (or application webhook).
 2. Filter: interview stage name equals `Take home`.
 3. Action: Praxicraft Assess **Invite Candidate**.
 </Step>
 <Step title="Map fields">
 | Assess field | Ashby field |
 |--------------|-------------|
 | Assessment | Your active assessment |
 | Email | Candidate primaryEmailAddress |
 | Name | Candidate Name |
 | External ID | Candidate ID |
 | Send email | `true` |
 </Step>
 <Step title="Score back">
 1. Trigger: `candidate.passed` / `candidate.failed`.
 2. Action: Ashby note on application (`applicationId` from the original event, or look up by `data.external_id`).
 3. Optional: advance or reject the application.
 </Step>
</Steps>
