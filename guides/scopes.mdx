description: "API key permissions — and which set to pick for common hiring automations."

Scopes limit what software can do with a key. Prefer the smallest set that matches the workflow.

## If you are recruiting / ops

You only care about scopes when someone with the [developer](/guides/roles) (or admin/owner) role creates a key for n8n, Zapier, or a custom integration. Ask them to use the **smallest** set that matches the workflow (invite-only vs full access).

Empty scopes = full access (legacy). Prefer limiting them.

Create keys: [Authentication](/guides/authentication).

## Scope matrix

| Scope | Allows |
|-------|--------|
| `organisation:read` | Org profile, billing summary, usage, team, member invites list, squads read, stats, audit log/export, developer health, integrations status |
| `organisation:write` | Limited `PATCH /org/`; create/update/delete hiring squads and squad members |
| `assessments:read` | List/get assessments and attached cases; browse platform cases |
| `assessments:write` | Create/update/duplicate assessments; attach/replace/remove cases |
| `invitations:read` | List/get invitations |
| `invitations:write` | Create, remind, cancel invitations |
| `candidates:read` | Assessment results and per-invite result detail |
| `cases:read` | List/get org custom cases |
| `cases:write` | Create/update/delete org custom cases |
| `pipelines:read` | List pipelines, enrollment status, notes |
| `pipelines:write` | Create/update pipelines & stages; enroll, reject, hold, unhold, advance; add notes |
| `webhooks:read` | List webhooks and deliveries |
| `webhooks:write` | Create/update/delete/test webhooks; retry deliveries |
| `interviews:read` | List interviews, templates, analysis, replay |
| `interviews:write` | Create/cancel/reschedule interviews and templates |
| `assistant:write` | CLI Ask AI (`POST /assistant/chat/`, Starter+) |

Missing scope → **403** `INSUFFICIENT_SCOPE`.

## Recommended sets

| Use case | Scopes |
|----------|--------|
| Invite + read results | `assessments:read`, `invitations:write`, `candidates:read` |
| Build assessments via API | `assessments:read`, `assessments:write`, `cases:read` |
| Webhooks only | `webhooks:read`, `webhooks:write` |
| Pipeline automation | `pipelines:read`, `pipelines:write`, `webhooks:write` |
| Live interviews | `interviews:read`, `interviews:write` |
| CLI Ask AI | `assistant:write` (plus scopes for any tools MCP should call) |
