## Shared behaviour

| Topic | Behaviour |
|-------|-----------|
| Auth | `PRAXICRAFT_API_KEY` or constructor `api_key` / `apiKey` / `WithAPIKey` |
| Base URL | Optional `PRAXICRAFT_API_BASE_URL` |
| Retries | Auto-retry on `429`, `500-504`, and transport errors (default 2 retries); honour `Retry-After` |
| Invite field | `invite_token` |
| Webhooks | Verify raw body with `whsec_…`. See [Verify webhooks](/sdks/webhooks) |

## Resources

Official clients expose org, assessments, invites, results, webhooks, and pipelines. The [CLI](/sdks/cli) also covers tasks, interviews, and integrations. Language-specific method names differ (`attach_tasks` vs `attachTasks` vs `AttachTasks`).

## When to use raw HTTP instead

- One-off curl debugging
- n8n / Zapier / Make HTTP modules; see [Automations](/integrations/automations)
