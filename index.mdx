Day-to-day work lives in the [dashboard](https://assess.praxicraft.com/assess). Candidates never see your API keys or ATS. Connect software when you need it through the Public API, SDKs, and webhooks.

![Praxicraft Documentation banner](/images/docs-banner.jpg)

## What you can do in Assess

Assess is a **hiring workspace for data talent**. You can run the full loop, or keep assessment-only invites if you already source elsewhere.

| Capability | What it is |
|------------|------------|
| **Jobs & careers** | Publish openings, custom apply forms, knockouts, public careers pages |
| **CV screening** | Rank applicants by deterministic match score; optional AI brief never changes that order |
| **Candidate profiles** | Org-wide people CRM: notes, tags, scorecards, merge |
| **Assessments** | Timed take-homes with coding, SQL, MCQ, and text tasks |
| **Live interviews** | AI, human, or hybrid rooms with analysis and replay |
| **Pipelines** | Multi-stage funnels (apply → screen → assess → interview) |
| **Webhooks & API** | Signed events and a Public API for ATS and automations |

Guides for each area live under the **Product** tab. Get started stays in **Guides**.
