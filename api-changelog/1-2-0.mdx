## Added

- `GET /org/usage/`: Daily series (mode-scoped, Starter+)
- `GET /org/developer/health/`: Destination / API health without secrets (mode-scoped, Starter+)
- `GET /org/billing/`: Plan, seats, quotas (org-global; no checkout IDs)
- `GET /org/audit-log/export/`: CSV/JSON export, capped (mode-scoped, Starter+)
