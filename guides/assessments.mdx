An assessment is a timed (or untimed) test: tasks, a passing score, and optional proctoring.

## If you are recruiting / ops

<Steps>
  <Step title="Create the assessment">
    In the [dashboard](https://assess.praxicraft.com/assess), create a new assessment. Give it a clear title hiring managers will recognise.
  </Step>
  <Step title="Add tasks">
    Attach platform tasks and/or your org’s [custom tasks](/guides/custom-cases). Order them the way candidates should see them.
  </Step>
  <Step title="Set rules">
    Time limit, passing score (default 70%), and proctoring options. See [Proctoring](/guides/proctoring).
  </Step>
  <Step title="Set status to Active">
    Drafts cannot receive invites. Activate when you are ready to send candidates.
  </Step>
  <Step title="Invite">
    Continue on [Invitations](/guides/invitations) (UI or API).
  </Step>
</Steps>

Archive assessments you no longer use instead of deleting them (there is no Public API delete).

## For engineers

Path ids accept **slug** or UUID — never the human title alone.

### Lifecycle

| Status | Meaning |
|--------|---------|
| `draft` | Editable; cannot invite |
| `active` | Accepts invitations |
| `archived` | Hidden from default lists |

### Endpoints

| Method | Path | Scope |
|--------|------|-------|
| GET | `/assessments/` | `assessments:read` |
| POST | `/assessments/create/` | `assessments:write` |
| GET | `/assessments/{slug}/` | `assessments:read` |
| PATCH | `/assessments/{slug}/update/` | `assessments:write` |
| POST | `/assessments/{slug}/duplicate/` | `assessments:write` |
| GET | `/assessments/{slug}/cases/` | `assessments:read` |
| POST | `/assessments/{slug}/cases/attach/` | `assessments:write` |
| PUT | `/assessments/{slug}/cases/replace/` | `assessments:write` |
| DELETE | `/assessments/{slug}/cases/remove/` | `assessments:write` → `204` |

List query: `status` (`active` \| `draft` \| `archived` \| `all`), `search`, `team_slug` / `team_id`, `cursor`, `page_size`.

### Create → attach → activate

```bash
curl -sS -X POST https://assess.praxicraft.com/api/v1/public/assessments/create/ \
  -H "Authorization: Bearer $PRAXICRAFT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Senior backend screen",
    "time_limit_minutes": 90,
    "passing_score": 70
  }'
```

Always starts as `draft`. Then attach tasks (`source`: `platform` or `org`):

```bash
curl -sS -X POST \
  "https://assess.praxicraft.com/api/v1/public/assessments/senior-backend-screen/cases/attach/" \
  -H "Authorization: Bearer $PRAXICRAFT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "cases": [{ "case_id": "CASE_UUID", "source": "platform" }] }'
```

After candidates have started, the lineup locks → **409** `TASKS_LOCKED`.

Activate:

```bash
curl -sS -X PATCH \
  "https://assess.praxicraft.com/api/v1/public/assessments/senior-backend-screen/update/" \
  -H "Authorization: Bearer $PRAXICRAFT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "status": "active" }'
```

Send **only** fields you mean to change on PATCH.

Duplicate: `POST /assessments/{slug}/duplicate/` → new draft (`201`). Candidates/results are not copied.

SDK helpers: [SDKs](/sdks/introduction).
