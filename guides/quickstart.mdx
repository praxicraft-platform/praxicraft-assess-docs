Two paths. Pick the one that matches your role.

## Path A: Dashboard only (recruiting / ops) (recruiting / ops)

No API key. No terminal.

<Steps>
 <Step title="Sign in to Assess">
 Open the [Assess dashboard](https://assess.praxicraft.com/assess).
 </Step>
 <Step title="Create or open an assessment">
 Add tasks, set time limit and passing score, then set status to **Active**. Invites fail if the assessment is still a draft.
 </Step>
 <Step title="Invite a candidate">
 Use **Invite** on that assessment. Enter email and name. Assess can send the email for you.
 </Step>
 <Step title="Watch for completion">
 When they finish, open **Results** on the assessment. Share the report with the hiring manager from the dashboard.
 </Step>
</Steps>

Want Greenhouse, Slack, or spreadsheets to update themselves? Ask an engineer to follow Path B, or use [n8n](/integrations/n8n) / [Automations](/integrations/automations).

---

## Path B: Public API (engineers)

Create an API key, list assessments, invite a candidate, and fetch their result.

### Prerequisites

- Organisation on **Starter** or above (Free cannot create API keys)
- An owner, admin, or [developer](/guides/roles) role (recruiters cannot mint keys)
- An **active** assessment (dashboard or [Assessments](/guides/assessments) API)

<Steps>
 <Step title="Create an API key">
 Open [Assess → Developer → API Keys](https://assess.praxicraft.com/assess/api), create a key, and copy it (shown once). Live keys start with `ct_live_`; switch the dashboard to **Test** to mint `ct_test_…`.

 Prefer least-privilege [scopes](/guides/scopes). Empty scopes grant full access (legacy).
 </Step>

 <Step title="Set your environment">
```bash
export PRAXICRAFT_API_KEY="ct_live_xxxxxxxxxxxxxxxx"
# Optional override (default: https://assess.praxicraft.com)
# export PRAXICRAFT_API_BASE_URL="https://assess.praxicraft.com"
```
 </Step>

 <Step title="List assessments">
<CodeGroup>

```bash curl
curl -sS https://assess.praxicraft.com/api/v1/public/assessments/ \
 -H "Authorization: Bearer $PRAXICRAFT_API_KEY"
```

```python Python
from praxicraft import Client

client = Client() # reads PRAXICRAFT_API_KEY
page = client.assessments.list()
for a in page["results"]:
 print(a["slug"], a["status"])
```

```ts Node
import { Client } from "@praxicraft/assess";

const client = new Client();
const page = (await client.assessments.list()) as {
 results: Array<{ slug: string; status: string }>;
};
for (const a of page.results) {
 console.log(a.slug, a.status);
}
```

```go Go
package main

import (
 "fmt"
 "log"

 praxicraft "github.com/praxicraft-platform/praxicraft-go"
)

func main() {
 client, err := praxicraft.New()
 if err != nil {
 log.Fatal(err)
 }
 page, err := client.Assessments.List(nil)
 if err != nil {
 log.Fatal(err)
 }
 for _, a := range page.Results {
 fmt.Println(a.Slug, a.Status)
 }
}
```

</CodeGroup>

 Pick an assessment with `"status": "active"`. Use its **`slug`** in the next step (not the display title).
 </Step>

 <Step title="Invite a candidate">
 Safe to retry: same email on the same assessment returns the existing invite. Default `send_email` is `false`. set `true` to have Assess email them.

<CodeGroup>

```bash curl
curl -sS -X POST \
 "https://assess.praxicraft.com/api/v1/public/assessments/YOUR_SLUG/invites/" \
 -H "Authorization: Bearer $PRAXICRAFT_API_KEY" \
 -H "Content-Type: application/json" \
 -d '{
 "email": "candidate@example.com",
 "name": "Jane Doe",
 "send_email": true
 }'
```

```python Python
invite = client.invites.create(
 "YOUR_SLUG",
 email="candidate@example.com",
 name="Jane Doe",
 send_email=True,
)
print(invite["invite_token"], invite.get("invite_url"))
```

```ts Node
const invite = (await client.invites.create("YOUR_SLUG", {
 email: "candidate@example.com",
 name: "Jane Doe",
 send_email: true,
})) as { invite_token: string; invite_url?: string };

console.log(invite.invite_token, invite.invite_url);
```

```go Go
send := true
invite, err := client.Invites.Create("YOUR_SLUG", praxicraft.InviteCreateParams{
 Email: "candidate@example.com",
 Name: "Jane Doe",
 SendEmail: &send,
})
if err != nil {
 log.Fatal(err)
}
fmt.Println(invite.InviteToken, invite.InviteURL)
```

</CodeGroup>

 Save **`invite_token`** from the response that is how you look up status and results later.
 </Step>

 <Step title="Fetch the result">
 Before they finish you get a short status message. After completion you get scores and pass/fail.

<CodeGroup>

```bash curl
curl -sS \
 "https://assess.praxicraft.com/api/v1/public/invites/INVITE_TOKEN/result/" \
 -H "Authorization: Bearer $PRAXICRAFT_API_KEY"
```

```python Python
result = client.results.retrieve(invite_token=invite["invite_token"])
print(result)
```

```ts Node
const result = await client.results.retrieve(invite.invite_token);
console.log(result);
```

```go Go
result, err := client.Results.Retrieve(invite.InviteToken)
if err != nil {
 log.Fatal(err)
}
fmt.Println(result)
```

</CodeGroup>

 In production, prefer [webhooks](/guides/webhooks) (`assessment.completed`) instead of polling.
 </Step>
</Steps>
